HRV metrics not available for CSV files.
HRV analysis requires raw ECG signal data from an EDF file. A CSV file only contains pre-computed summary statistics — the beat-to-beat RR interval series needed for SDNN, RMSSD, SD1/SD2, and entropy metrics is absent.
To get HRV data, upload the original EDF recording from the PSG device. Any HRV columns present in the CSV (e.g. sdnn, rmssd) will still be displayed if found.
